# مِخيط Pro — Flutter Mobile

نسخة Flutter حقيقية ومستقلة من نظام **مِخيط Pro** لإدارة أعمال الخياطة النسائية بالقطعة.

## الفرق عن نسخة الويب

هذه النسخة **لا تحتاج تشغيل الكمبيوتر ولا Python ولا خادم محلي**. التطبيق نفسه يعمل على الهاتف ويحفظ البيانات محليًا في SQLite.

- Flutter + Dart
- SQLite على الهاتف
- واجهة عربية RTL ومصممة للموبايل
- لا حسابات مستخدمين
- لا تخزين سحابي
- لا اتصال بالإنترنت مطلوب للاستخدام اليومي

> ملاحظة: تصدير PDF يستخدم خطًا عربيًا موجودًا محليًا في نظام Android، لذلك لا يحتاج تنزيل خط من الإنترنت. التطبيق يبحث تلقائيًا عن خطوط Arabic/Naskh/Kufi إذا اختلف اسم الخط بين الشركات.

## الوظائف الموجودة

### الأعمال
- إضافة وصف اختياري.
- تحديد عدد القطع.
- بدون تعديلات: `عدد القطع × سعر القطعة`.
- عند اختيار تعديل واحد أو أكثر: **سعر القطعة العادي لا يدخل في الحساب**.
- كل تعديل يبدأ افتراضيًا بـ **500 ريال**.
- تستطيع تغيير سعر كل تعديل.
- تستطيع تحديد عدد القطع التي يطبق عليها كل تعديل.
- تعديلات جاهزة: الطول، العرض، طول الكم، عرض الكم، توسيع، تضييق، تعديل الكتف، تعديل الياقة، تغيير سحاب.
- إضافة تعديل مخصص.
- الإجمالي يتغير مباشرة.
- تعديل العملية بدون تغيير تاريخها الأصلي.

### السحبيات
- تسجيل مبلغ السحب.
- ملاحظة اختيارية.
- التاريخ تلقائي.
- تعديل السحب بدون تغيير التاريخ الأصلي.

### الحذف الآمن
- الحذف العادي ينقل العملية إلى **سلة المحذوفات**.
- استعادة العملية.
- حذف نهائي منفصل مع تأكيد.

### التقارير
خمسة تقارير مستقلة:
1. تقرير الأعمال المنجزة.
2. تقرير السحبيات.
3. التقرير المالي الشامل.
4. ملخص أسبوعي من السبت إلى الجمعة.
5. ملخص شهري كامل، مقسم محاسبيًا إلى أسابيع السبت–الجمعة.

كل تقرير يدعم **PDF مفصل** ومشاركة/طباعة من الهاتف.

### حماية البيانات
- SQLite بأموال مخزنة كأعداد صحيحة `INTEGER`.
- نسخة احتياطية تلقائية يومية داخل التطبيق مع الاحتفاظ بآخر 14 نسخة.
- تصدير نسخة قاعدة البيانات من قسم «المزيد».
- استعادة نسخة `.db` بعد التحقق من سلامة الملف.
- قبل الاستعادة، ينشئ التطبيق نسخة أمان من البيانات الحالية.
- بنية قاعدة البيانات متوافقة مع Mikhyat Pro V5 على الكمبيوتر.

# التشغيل في Flutter

## المتطلبات
- Flutter 3.35 أو أحدث.
- Android Studio أو Android SDK.
- هاتف Android أو Emulator.

## أسرع طريقة على Windows

1. فك ضغط المشروع.
2. افتح المجلد.
3. شغّل:

`RUN_FLUTTER.bat`

الملف سيقوم تلقائيًا بإنشاء ملفات منصة Android إذا لم تكن موجودة ثم ينفذ:

```bash
flutter pub get
flutter run
```

## من Android Studio

افتح **مجلد المشروع نفسه** الذي يحتوي على `pubspec.yaml`.

إذا لم يكن مجلد `android` موجودًا، افتح Terminal داخل المشروع ونفذ مرة واحدة:

```bash
flutter create . --platforms=android --org com.mikhyat --project-name mikhyat_pro
flutter pub get
```

ثم شغّل التطبيق من Android Studio.

# إنشاء APK

على Windows شغّل:

`BUILD_APK.bat`

السكريبت ينفذ الاختبارات أولًا ثم يبني Release APK.

بعد نجاح البناء ستجد الملف هنا:

`build/app/outputs/flutter-apk/app-release.apk`

أو يدويًا:

```bash
flutter pub get
flutter test
flutter build apk --release
```

# نقل بيانات نسخة الكمبيوتر V5 إلى Flutter

في نسخة الكمبيوتر V5 تكون قاعدة البيانات عادة هنا:

```text
%LOCALAPPDATA%\MikhyatPro\data\mikhyat.db
```

1. أغلق نسخة الكمبيوتر قبل نسخ الملف.
2. انسخ `mikhyat.db` إلى الهاتف.
3. افتح تطبيق Flutter.
4. ادخل **المزيد → استعادة نسخة**.
5. اختر ملف `mikhyat.db`.
6. التطبيق يتحقق من سلامة قاعدة البيانات، ويحفظ نسخة أمان من بيانات الهاتف الحالية ثم يستورد البيانات.

## ملاحظة البناء في هذه الحزمة

تم تجهيز **كود Flutter الكامل** وملفات الاختبار وسكربتات Windows. ملفات Android الأصلية (`android/`) يتم توليدها بواسطة Flutter SDK على جهازك عبر `RUN_FLUTTER.bat` أو `flutter create .`، وهذا يضمن أنها تطابق إصدار Flutter/Gradle المثبت لديك بدل تضمين قالب Android قديم قد يتعارض معه.

> ملاحظة التحقق: تم فحص بنية ملفات Dart وYAML ومنطق قاعدة البيانات والتسعير في هذه الحزمة. بناء APK فعليًا يتطلب Flutter SDK وAndroid SDK، وهما غير موجودين في بيئة إنشاء هذه الحزمة؛ لذلك شغّل `BUILD_APK.bat` على جهاز Flutter لديك ليجري `flutter test` ثم يبني APK.
